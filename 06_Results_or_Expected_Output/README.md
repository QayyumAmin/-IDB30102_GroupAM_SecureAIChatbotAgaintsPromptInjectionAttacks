# 06_Results_or_Expected_Output

This folder is prepared for the evaluation stage of the project. At the current proposal stage, it contains the expected outcomes, evaluation metrics and a blank results template.

Actual values should only be added after the prototype has been tested. Do not replace the blank results with invented percentages.

## Files
- `evaluation_metrics.md` - definitions and formulas used in the evaluation.
- `expected_outcomes.md` - expected direction of the results without fabricated numbers.
- `results_template.csv` - table to record the real output of each test case.
- `sample_expected_outputs.json` - examples of the system behaviour expected for safe and malicious prompts.
